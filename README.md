# Mental Health Support Chatbot

## Overview
A conversational mental health support chatbot designed to provide basic emotional support, coping suggestions, and guided responses for users experiencing stress, anxiety, or low mood. This system focuses on safe conversational assistance and structured response mapping.

## Features
- Emotion-aware conversational replies
- Intent detection
- Context-based response flow
- Coping suggestions
- Modular response engine
- Lightweight execution

## Tech Stack
- Python
- NLP processing
- Intent JSON dataset
- Rule-based response mapping

## How It Works
1. User input is normalized
2. Intent is detected
3. Matching support response is selected
4. Suggestion + follow-up is generated

## Project Structure
src/ → chatbot logic  
data/ → intent dataset  
screenshots/ → demo output images  

## How To Run
pip install -r requirements.txt
python src/chatbot.py

## Example Inputs
"I feel anxious"  
"I am stressed about my career"  
"I feel lonely"

## Safety Notice
Not a replacement for professional mental health care. Educational support tool only.
